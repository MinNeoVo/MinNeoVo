## 🚀 Featured Projects

### 🥗 ChayBook — Vegetarian Support Application

A team project developed as part of the SWP391 course at FPT University.

**Objective:** Build a web application that supports vegetarian users with nutrition-related content and community features.

**Key Features:**
- User authentication and profile management.
- Articles, recipes, and community content.
- BMI analysis.
- AI-assisted nutrition features, where implemented.

**Technology:** React, Tailwind CSS, Java, Spring Boot, SQL Server.

**My Contribution:** Full-stack development, UI implementation, API integration, and team collaboration.

[**View ChayBook Repository →**](https://github.com/MinNeoVo/ChayBook)

---

### 💡 Study Buddy — Landing Page

A responsive landing page for a peer-learning community that helps FPT University students connect, find study partners, and learn together.

**Role:** Frontend Developer.

**What I worked on:**
- Implemented the landing page UI using reusable React components.
- Built responsive layouts for different screen sizes.
- Integrated navigation to the Google Form for student registration.
- Worked with Git and GitHub and deployed the website using Vercel.

**Technology:** React, Vite, Tailwind CSS, JavaScript, Git, GitHub, Vercel.

**What I learned:** Component-based UI development, responsive design, reusable styling, Git workflow, and frontend deployment.

[**View Study Buddy Repository →**](https://github.com/MinNeoVo/Studdy-Buddy-Website)
